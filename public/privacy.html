개인정보처리방침

시행일: 2026년 4월 15일  |  최종 수정: 2026년 4월 15일

J여관은 사용자의 여행 데이터를 외부 서버에 전송하거나 수집하지 않습니다.
모든 여행 기록(일정, 지출, 체크리스트, 장소, 일기 등)은 사용자의 기기에만 저장됩니다. 본 방침은 앱이 사용하는 제3자 서비스(Google AdMob, Gemini API)에 대한 정보를 포함합니다.

1. 수집하는 정보

J여관 앱 자체는 개인 식별 정보를 수집하거나 저장하지 않습니다. 사용자가 앱에 입력하는 모든 데이터는 사용자의 기기 내 로컬 저장소(IndexedDB)에만 보관됩니다.

데이터 유형 저장 위치 외부 전송
여행 정보 (일정, 도시, 날짜) 기기 내 IndexedDB 없음
지출 내역 기기 내 IndexedDB 없음
체크리스트 항목 기기 내 IndexedDB 없음
방문 장소 기기 내 IndexedDB 없음
여행 일기 / 메모 기기 내 IndexedDB 없음
앱 설정 (언어, 글꼴, 환율 등) 기기 내 localStorage 없음
Gemini API 키 (선택 입력) 기기 내 localStorage Google Gemini API

2. 제3자 서비스

앱은 아래의 제3자 서비스를 사용합니다. 각 서비스는 해당 사업자의 개인정보처리방침이 적용됩니다.

서비스 제공사 용도 데이터 전송
Google AdMob Google LLC 광고 노출 광고 식별자(GAID/IDFA), 기기 정보
Gemini API Google LLC AI 자동 생성 (선택 기능) 사용자가 설정한 프롬프트 텍스트

Google AdMob: 광고 맞춤화를 위해 광고 식별자 및 기기 정보를 수집할 수 있습니다. 자세한 내용은 Google 개인정보처리방침을 참고하세요.

Gemini API: AI 자동 생성 기능은 선택 사항입니다. 사용자가 직접 발급한 API 키를 앱에 입력한 경우에만 활성화되며, 생성 요청 시 프롬프트 텍스트가 Google Gemini 서버로 전송됩니다. 개인 식별 정보는 포함되지 않으며, API 키는 기기에만 저장됩니다.

3. 광고 식별자 사용

Android 기기에서는 Google AdMob 광고 표시를 위해 Google 광고 식별자(GAID)가 사용될 수 있습니다. 사용자는 기기 설정에서 광고 맞춤화를 거부하거나 광고 식별자를 초기화할 수 있습니다.

  • Android: 설정 → Google → 광고에서 '관심 기반 광고 선택 해제' 또는 '광고 ID 재설정'

4. 데이터 보관 및 삭제

모든 여행 데이터는 사용자의 기기에만 저장되므로, 앱 삭제 시 자동으로 완전히 삭제됩니다. 개발사는 해당 데이터에 접근할 수 없습니다.

  • 앱 내 설정 → 데이터 관리에서 여행별 데이터를 직접 삭제할 수 있습니다.
  • 앱을 기기에서 삭제(제거)하면 모든 로컬 데이터가 영구 삭제됩니다.

5. 아동 개인정보 보호

J여관은 13세 미만 아동의 개인정보를 의도적으로 수집하지 않습니다. 앱 자체는 개인 식별 정보를 수집하지 않으므로 아동도 안전하게 사용할 수 있습니다. 단, 제3자 광고 서비스(AdMob)의 정책에 따라 아동 대상 광고 설정이 적용됩니다.

6. 보안

여행 데이터는 기기 내 IndexedDB에 저장되며, 기기의 보안 설정(PIN, 생체 인증 등)에 의해 보호됩니다. Gemini API 키는 기기의 localStorage에 저장되므로 타인과 기기를 공유하는 경우 주의가 필요합니다.

7. 방침 변경

본 개인정보처리방침은 법령 변경 또는 서비스 변경 시 업데이트될 수 있습니다. 변경 시 앱 내 공지 또는 본 페이지의 '시행일' 업데이트를 통해 안내합니다.
